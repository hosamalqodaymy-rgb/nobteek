نوبتيك هوية ومكونات P01 الإصدار 1.0

المعاينة دون تثبيت أو خادم
افتح Nobteek_P01_Preview.html في المتصفح. هذا الملف يجمع الخطوط والشعار والألوان والمكونات داخله.
المعاينة نموذج هوية ومكونات فقط. أزرارها لا تنشئ حجوزات فعلية.

ملفات المصدر
brand.config.json المصدر المركزي للاسم والنصوص والألوان والخط والمقاسات وحالات البيانات.
styles/brand.generated.css وbrand.generated.js مخرجات توليد، لا تعدل يدويا.
styles/components.css وcomponents.js المكونات المشتركة التي تستهلك الرموز المولدة.
assets ملفات SVG وPNG للشعار وأيقونات 192 و512 و1024 والغلافين والهوية.
fonts ملفات Tajawal الأصلية ونسخ WOFF وترخيص OFL وسجل مصدرها.
preview/index.html معاينة المصدر متعددة الملفات، وتحتاج خادما محليا عند فحصها عبر HTTP.

إعادة بناء الأصول من جذر المشروع
python3 tools/build_p01.py
node tools/rasterize_p01.cjs
python3 tools/bundle_p01_preview.py
python3 tools/prepare_p01_preview.py
node tools/validate_p01_assets.cjs

متطلبات التوليد فقط
Python 3.11 أو أحدث وfontTools وlibharfbuzz وlibfribidi وReportLab لدليل PDF.
Node مع sharp لتصدير PNG، ومع Playwright إذا استخدم فحص المتصفح المحمول إلى بيئة تدعمه.
ملف المعاينة المنفرد وملفات SVG وPNG النهائية تعمل دون هذه الأدوات ودون اتصال خارجي.

الفحص في البيئة المدارة
استخدم معاينة sites-preview والمتحكم المعتمد بالمتصفح، ولا تطلق متصفحا أو خادما مستقلا.
tools/validate_p01.cjs أداة اختيارية لبيئات التطوير العادية التي تملك متصفح Playwright؛ لم تنفذ بنجاح داخل البيئة المدارة هنا.
الفحوص الحالية الفعلية في results/p01_validation.json تفصل 32 فحص أصول و32 فحص متصفح و5 تفاعلات فعلية.
لقطات المتصفح ليست ضمن الحزمة؛ صور الهوية المرفقة مصممة ومصدرة من SVG.

حدود التسليم
الاسم اسم عمل يحتاج التحقق التجاري قبل النشر العام. لا يوجد حجز علامة أو شراء نطاق.
قواعد P00 محفوظة دون تغيير، وتبدأ الرحلات التفاعلية الكاملة في P02.
تظل الجداول المالية والتحصيل والخدمات المدفوعة إلى P13.
