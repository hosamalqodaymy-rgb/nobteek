# نوبتيك | Nobteek

تطبيق عربي لتنظيم حجوزات العيادات والدور في اليمن. يحتوي هذا المستودع على المصدر الفعلي والأعمال المحفوظة من P00 إلى P07، بما فيها الهوية والنموذج التفاعلي وقواعد العمل والاختبارات والتوثيق.

تغييرات P07 محفوظة على فرع `work/p07-reception-20261108` وجاهزة للمراجعة؛ نقلها إلى `main` ينتظر موافقة المستخدم.

## حالة التنفيذ

| المرحلة | العمل المحفوظ |
| --- | --- |
| P00 | قواعد العمل والمواصفات |
| P01 | الاسم والهوية والألوان والأصول البصرية |
| P02 | النموذج التفاعلي ورحلات الاستخدام |
| P03 | أساس التطبيق وقاعدة البيانات والهجرات |
| P04 | الحسابات والأمان وصلاحيات العيادات |
| P05 | إعداد العيادة والأطباء والجلسات وإصداراتها |
| P06 | طلبات الحجز العامة وحجوزات الاستقبال والتأكيد والرفض والإلغاء والتأجيل وحماية السعة من التنافس |
| P07 | الاستقبال والحضور المباشر والتذكرة الثابتة والغياب والعودة وإرجاء الدور المصرح |

المرحلة التالية **P08: شاشة الطبيب ودورة الزيارة**. مرحلة الدفع والتحصيل والربط المالي مؤجلة إلى **P13**. الحسابات السحابية وحدها لا تعني أن التطبيق منشور أو أن قاعدة بياناته رُفعت.

نجح 139 اختبارًا مع 945 تحققًا، و14 فحص متصفح لـP07، بما فيها تنافس موظفين مختلفين على الوصول والعودة إلى نهاية الانتظار. [تقرير P07](results/p07_validation.json). الهاتف الفعلي والنشر المتصل ما زالا معلقين؛ APK السابق معاينة P06 محلية فقط.

## تشغيل نسخة تطوير

اتبع [الدليل المحفوظ](docs/Nobteek_P06_Setup_and_Test_AR.txt) من مجلد `application`. ملفات `.env.example` و`.env.testing.example` قوالب فقط؛ انسخها محليًا وأدخل إعدادات بيئتك خارج Git. ثبّت الاعتماديات من ملفات القفل، وأنشئ مفتاح التطبيق محليًا، وجهّز PostgreSQL، ثم نفّذ الهجرات والاختبارات قبل توصيل أي بيئة حقيقية.

لا تتضمن النسخة ملفات البيئة المحلية أو كلمات مرور قاعدة البيانات أو مفاتيح التطبيق. توجد قيم ثابتة مخصصة للاختبارات وقاعدة بيانات مؤقتة في CI؛ لا تستخدمها لحسابات أو خدمات فعلية. تثبيت الاعتماديات وملفات البناء يتم في بيئة التشغيل؛ لم تُضمّن مجلدات `vendor` أو `node_modules` أو بيانات التشغيل.
